Imperium OS Privacy Policy

Last updated: August 12, 2026

Overview

Our commitment

Imperium OS is a protection and productivity extension that filters domains, network requests, and navigations to help you avoid sites and content that interfere with productive browsing. This policy explains what data the extension processes, why it does so, where that data lives, and how you can control it. Simply put: Imperium OS keeps your data local, never sells it, and only reaches out to the internet when you actively use a feature that requires it.

Data

Data the extension processes

To provide its core functions, Imperium OS processes the following data:

  • Web history: URLs, domains, and navigation events needed to apply the extension's filtering rules.
  • Site content: elements of web pages required for the extension's protection features to operate.
  • Browsing activity: network requests and navigation destinations evaluated by the filter.
  • Local configuration: allowed sites, channels, preferences, language, protection state, and verification cache.
  • Optional YouTube key: if you enter one, it is stored locally and used only to perform the YouTube channel searches you request.

Use

How the data is used

Data is used exclusively for Imperium OS's core purpose: blocking classified sites and requests, applying navigation controls, showing your protection state, and preserving your settings across sessions and updates. Imperium OS does not use your data for advertising, commercial profiling, credit assessment, or lending.

Storage

Storage and transfer

The extension's configuration and state are stored locally using chrome.storage. Navigation events intended for the Sentinel service are sent only to the local Imperium OS service on your own device, never to a third-party server.

Some optional directory and search features may make requests to DuckDuckGo, Google/YouTube, or other queried domains in order to return results or verify that a domain is reachable. These requests occur only when you actively use those features.

Code integrity

Remote content and remote code

Imperium OS does not download or execute remote JavaScript or WebAssembly. All executable code in the extension is bundled in the published release. External requests only receive data, search results, or API responses; they are never used to run code on your device.

Retention

Retention and deletion

Local data remains in your browser profile until you modify it, uninstall the extension, or clear the extension's data from Chrome. External requests and the Sentinel service apply their own retention policies.

Privacy

Sharing and sale

Imperium OS does not sell user data and does not transfer it to third parties for any purpose other than the extension's single purpose. The transfers described above occur only when necessary to provide a feature you have requested.

Security

Security

Local data stays on your device and is never transmitted to Imperium OS servers. Any credentials you provide (such as the optional YouTube key) are stored in your browser profile and used solely for the feature that requires them.

Control

Your choices

  • Clear the extension's data from chrome://extensions at any time.
  • Uninstall the extension to stop all processing immediately.
  • Edit or remove locally stored settings and the optional YouTube key through the extension's interface.

Updates

Changes to this policy

If features or the data processed change, this policy will be updated before or at the same time as the corresponding Imperium OS release. Material changes will be reflected here with an updated "Last updated" date.

Imperium OS does not sell your data and does not use it for advertising, commercial profiling, credit, or lending.
