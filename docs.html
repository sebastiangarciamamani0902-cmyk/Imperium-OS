Imperium OS Documentation

Guides for the Imperium OS desktop application and the browser extension. Learn how to install, use, and manage both, and how your data is handled.

Desktop

Getting Started

Imperium OS is a full desktop application for Windows 10 (build 1809) and later, and Windows 11. It is distributed as a signed installer (ImperiumOS_Setup_32.0.0.exe) built with Inno Setup, and it runs with administrative privileges.

  • Requirements: Windows 10 1809+ or Windows 11, 64-bit, plus administrator rights to install.
  • Install: run the installer and follow the steps. It installs the ImperiumOS.exe application, registers it in the Start Menu, and optionally adds a desktop shortcut and a launch-on-login task.
  • First launch: a full-screen boot splash loads configuration, language, memory, achievements, integrity, neural engine, sleep mode, skins, missions and AI, then opens the main workspace.
  • Profile: a new profile starts at Level 1 with 0 credits, 0 XP and 100% integrity,.

Your data lives in %LOCALAPPDATA%\Imperium OS, stored in local SQLite databases. A single instance is enforced: opening a second copy focuses the existing window.

Note

The installer also hardens the system: it adds a hosts-file blocklist for known distractors, terminates distracting apps (Discord, Telegram, WhatsApp, Steam, Spotify, Netflix and others), flushes DNS, and enables notification "ghost mode".

Desktop

How it works

A session is a timed focus block you commit to. Imperium OS tracks what you actually did, grades the result, and rewards or penalizes you accordingly.

Modes

  • Deep Work — the core timer. Pick 25, 50, 90, 180 minutes or a custom duration. You commit to a task before starting. Requires a configured AI model for verification.
  • Sprint — an acceleration protocol that counts timer steps faster (5s per tick) and awards bonus progress toward sprint achievements.
  • Meditation — guided breathing protocols (Tactical 2, Box 5, Relax 15, and unlockable ones like Wim Hof and deep focus) with mantras and audio. Rewards XP = minutes × 10 and Credits = minutes × 5.

Session grading

Each completed session is judged. If AI is available, the productivity score comes from analyzing your evidence; otherwise a heuristic reviews your real browser history. Results map to grades from S+ (95+) down to F-. Higher grades pay credits, XP and integrity; failure costs you all three.

Grade rewards

S+ +800 credits · S +500 · A +250 · B +100 · C 0 · D −150 · E −300 · F −500 · F- −800 (XP and integrity change accordingly).

Ranks, integrity & anti-cheat

  • Ranks: your XP determines your title — Novato, Elite, Comandante, Dios.
  • Integrity: starts at 100%. Tampering with the database, cheating the clock, or racking up failing sessions drops it. At 0, the whole UI is locked down and missions are frozen.
  • Protection: the database is signed (SHA-256), the clock is checked against an external time source, and a background engine monitors distracting activity and captures periodic evidence.
  • Skins, Music & Shop: unlock 20 interface skins, buy focus audio tracks, and customize the battlefield with credits earned from sessions and achievements.

Desktop

Reports

The Report Vault is your evidence gallery. Every completed mission stores proof with its metadata so you can review what actually happened in each session.

  • Evidence: periodic captures and a final proof screenshot per mission, plus a tile mosaic when AI analysis is active.
  • Metadata: each entry records the date/time, grade (S+ to F-), score out of 100, and a short task description.
  • Navigation: browse the full session gallery and inspect the stored metadata for any mission.
  • Cleanup: use the Weekly and Monthly buttons to delete evidence older than 7 or 30 days and reclaim disk space.

Desktop

Updates

New desktop releases are distributed through the official Imperium OS installer. Installing a newer version preserves your existing profile, unless the release notes specify otherwise.

Uninstall

To remove the desktop application, use the standard uninstaller from the Start Menu (Imperium OS program group).

  • Removes the application files and the ImperiumOS launch-on-login registry entry.
  • Deletes the profile: session data, vault, evidence, logs, cache and local databases in %LOCALAPPDATA%\Imperium OS.
  • Cleans up temporary state files created during use.

Note

Removing the Core application does not remove the browser extension. Uninstall the extension separately (see the Extension > Uninstall section).

Extension

Installation

Imperium OS for Chrome provides browser protection and site blocking. It is installed as a managed extension using your organization profile.

  • Requirements: Windows 10/11, Google Chrome, and administrator rights for managed installation.
  • Store install: install from the Chrome Web Store so it is force-deployed to browsers on your managed device.
  • Managed installation: Imperium OS can be force-installed on Chrome through Windows/Chrome management policies. This prevents removal from the normal extension manager. An official installer applies the store-force policies, periodic guard tasks, and the incognito/guest/account profile blocks.

Admin required

Managed installation relies on Windows/Chrome policies that require an administrator account on the device. A standard user cannot trigger this install.

Extension

Blocking

The extension filters unwanted sites using several layers, so distractions and harmful content are cut off before and after page load.

  • Rules: hard blocklists shut down known distractors and adult content instantly.
  • Scoring engine: domains and pages are scored by reputation, path, query, and search-signal heuristics. Scores above the block threshold are refused automatically.
  • Network level: a declarative ruleset blocks major distracting domains at the network layer before the page renders.
  • Browsing protection: when a blocked site is opened it is redirected to a blank tab. Incognito, guest and new-account profiles are blocked, and tabs containing blocked content are closed.
  • YouTube Guard: YouTube is locked unless the sealed apostles (allowed channels) are configured.

Extension

Whitelist

You decide which sites are allowed to pass the filter.

  • Allow a site: open the extension popup, go to the White List tab, type the handle, name or URL, and press Add. The site is then permitted.
  • Remove: delete any site from the list with its × button, or reset the whole list.
  • By path: some domains are opened only at specific paths (for example a work tool or a direct message), while the rest stays blocked.
  • Self-guarding: the whitelist is auto-corrected — a site the engine considers malicious or adult cannot sneak in, even if added by hand.
  • YouTube: seal your apostle channels for 7 days or 1 month to keep YouTube locked to approved channels only.

Extension

Updates

Extensions installed from the Chrome Web Store receive updates automatically through Chrome when a new version is published. No action is required on your part.

Uninstall

Because the extension is managed by system policy, it cannot be removed from Chrome’s normal extension manager.

To remove Imperium OS cleanly, use the official administrator uninstall procedure. It stops the guard/update tasks, removes the Imperium OS policies, restores registry values, clears the hosts-file block and DNS cache, and deletes the extension files.

Admin only

Removing the managed extension should be done through the official administrator procedure, which removes the Imperium OS policies and associated protection components.

Copy the script below, save it as imperium_uninstall.ps1, then run it as Administrator in PowerShell to roll back what Imperium OS installed on this device.

    Write-Host "Administrator permissions required. Elevating..." -ForegroundColor Yellow
    Start-Process powershell -Verb RunAs -ArgumentList "-NoProfile -ExecutionPolicy Bypass -File `"$PSCommandPath`""
    exit
}

Remove-ItemProperty $fcList -Name "1" -ErrorAction SilentlyContinue
    Write-Host "  [OK] Removed ExtensionInstallForcelist[1] (Imperium)" -ForegroundColor Green

$curSet = (Get-ItemProperty $polBase -Name "ExtensionSettings" -ErrorAction SilentlyContinue).ExtensionSettings
if ($curSet) {
    try {
        $obj = $curSet | ConvertFrom-Json
        if ($obj.PSObject.Properties.Name -contains $ExtensionID) {
            $obj.PSObject.Properties.Remove($ExtensionID)
            if ($obj.PSObject.Properties.Count -gt 0) {
                New-ItemProperty $polBase -Name "ExtensionSettings" -PropertyType String -Value ($obj | ConvertTo-Json -Compress) -Force | Out-Null

Support

Troubleshooting

  • The extension does not persist after restart. — Re-run the installer as Administrator and confirm the device is admin + domain / Azure AD joined so the force-install policy applies.
  • Chrome reports "installed by administrator" with no Remove button. — That is expected for a managed, force-installed extension.
  • Core integrity reaches 0 and missions are locked. — This is anti-cheat protection. Avoid editing the database or changing the system clock; recover by completing the required reset flow from the app.
  • Integrity warnings from clock drift. — The app verifies the real time against an external source. If your clock drifts, synchronize it.
  • I cannot open a second copy of the app. — Only one instance runs at a time; it focuses the existing window.
  • Deep Work won’t start. — You must configure and verify an AI model first; a mission cannot be committed without it.

Support

Known Limitations

  • The managed installation requires administrator privileges.
  • Force-installation depends on Chrome management policies.
  • Browser-specific behavior may differ outside supported Chrome configurations.
  • AI verification requires a configured AI provider.
  • Local evidence captures consume disk space.

Privacy

Privacy & Data

Imperium OS is designed with a local-first privacy model. Your focus history and personal data stay on your device. This section is kept in sync with the published Privacy Policy.

  • Local storage: missions, grades, credits, XP, achievements, evidence and browsing activity are stored in local SQLite databases under %LOCALAPPDATA%\Imperium OS. Nothing is uploaded to a production server.
  • Evidence captures: periodic screenshots and final proof are kept locally and can be deleted with the Weekly/Monthly cleanup. An immutable local ledger records your activity.
  • AI analysis: when an AI model is configured and enabled, productivity scoring is performed via the model provider API (for example Gemini). Imperium OS never hardcodes or stores your API keys unencrypted for third-party use.
  • Telemetry: internal status and a local telemetry service run on your machine for self-monitoring; the sleep guardian also checks the current time over the network to detect clock tampering.
  • Your control: uninstall the Core application to delete its local profile, and run the extension uninstall script to remove browser policies and the hosts-file block.
